# AI 协作与科研创作｜自然语言引导文档

这组文档写给希望与 AI 深入合作的人。它们关注的不是让每次回答执行一套固定步骤，而是让 AI 能够理解我们真正要解决的事情，主动运用知识与判断，提出值得讨论的想法，并交付有用的结果。


| 文件 | 适合什么时候使用 |
| --- | --- |
| `00_通用AI协作思考与表达原则.md` | 希望 AI 在各种任务中更准确地理解意图、独立判断、主动纠偏，并直接推动事情完成 |
| `01_科学研究创新探索与路径引领.md` | 有初步的研究想法、发现不清楚的现象，想找到真正值得探索的问题和创新切口 |
| `02_已有成果分析改进与相关研究检索.md` | 已有实验、数据、模型或系统，希望读懂结果、找到改进机会，并开展有针对性的研究检索 |
| `03_学术写作科学叙事与成果发表.md` | 准备或修改论文、图表、审稿回复和投稿材料，希望研究被准确而有力量地表达 |
| `Creative_世界知识启发与自由探索.md` | 希望跳出已有视野，让广泛的世界知识为当前问题带来意外而有用的新联系 |
| `Creative_示例推演_EIT_SAR_SDR_OFDM.md` | 想查看跨技术领域联想的具体案例；仅在需要时参考 |
| `Creative_远距知识跃迁示例_科研_知识_内容.md` | 想了解科研、知识应用与内容探索中的开放联想案例；仅在需要时参考 |
| `04_本轮用户请求与对话演进.md` | 希望了解这些文本如何从真实对话和多轮反馈中逐步形成 |

使用时，可以直接提出正在面对的问题，然后附上一份适合的文本。例如，分析已经完成的实验就选 02，改论文就选 03，想发现未知研究机会就选 01；讨论不局限于科研时，00 和 Creative 也可以各自独立使用。

Creative 尤其适合在原有思路已经反复讨论、希望主动听到陌生领域启发时调用。两份 Creative 案例不必默认加载，以免实例本身反过来限定联想范围。必要时，可以在某个启发出现后继续进行 Creative Debug，检查它能否在当前问题中真正发挥作用。
